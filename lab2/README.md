# Лабораторная работа №2 — Задача 4

Перемножение больших матриц с распараллеливанием на C#.

## Описание

Программа умножает две квадратные матрицы размером N×N. Реализованы две версии:
- последовательная (классический тройной цикл i-j-k);
- параллельная (внешний цикл распараллелен через `Parallel.For`).

Распараллеливание внешнего цикла корректно, так как каждая итерация пишет
в собственную строку результирующей матрицы. Число потоков и размер задачи
передаются через командную строку.

## Требования

- .NET 8.0 SDK или новее

## Сборка

```bash
dotnet build -c Release

## Запуск

dotnet run -c Release -- <размер_матрицы> <число_потоков>

## Пример

# последовательная версия, матрица 500x500
dotnet run -c Release -- 500 0

# параллельная версия, 2 потока
dotnet run -c Release -- 500 2

# параллельная версия, 4 потока
dotnet run -c Release -- 500 4

# параллельная версия, 8 потоков
dotnet run -c Release -- 500 8
